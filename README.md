# วิเคราะห์ฟุตบอล

ค้นหาทีม เลือกแมตช์ที่ยังไม่เริ่ม แล้วแอปจะดึงฟอร์มย้อนหลัง ผลการแข่งขันในฤดูกาล และราคาจากเจ้ามือ เพื่อคำนวณสกอร์คาดการณ์ โอกาสชนะ–เสมอ–แพ้ สูง/ต่ำ และ BTTS

## ชื่อทีมควรพิมพ์แบบไหน

พิมพ์เป็นภาษาอังกฤษ เช่น `Arsenal`, `Manchester United`, `Real Madrid` ผู้ให้ข้อมูลฟรีส่วนใหญ่ใช้ชื่ออังกฤษเป็นมาตรฐาน จึงแม่นกว่า

แอปรองรับความต่างของชื่อให้เอง:
- ตัดคำอย่าง FC, CF, AC ออกอัตโนมัติ (`Arsenal FC` = `Arsenal`)
- ขยายชื่อย่อ (`Man Utd` = `Manchester United`)
- ชื่อเรียกที่รู้จัก เช่น `Spurs`, `Wolves`, `PSG`, `Barca` และชื่อไทยบางทีม เช่น `อาร์เซนอล`, `แมนยู`
- ถ้าชื่อกำกวม เช่น `Manchester` ที่ตรงทั้งยูไนเต็ดและซิตี้ แอปจะไม่เดา แต่จะให้เลือกจากรายการ

เพิ่มชื่อเรียกใหม่ได้ใน `app/data/aliases.json` โดยใส่ชื่อทางการเป็นคีย์และชื่อเรียกเป็นรายการ

## ติดตั้งและรันในเครื่อง

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env          # ใส่ token และ key ของคุณ
export $(grep -v '^#' .env | xargs)
uvicorn app.main:app --reload
```

เปิด http://127.0.0.1:8000

ทดสอบ: `pip install -r requirements-dev.txt && pytest -q`

## ขอ API key

| บริการ | ใช้ทำอะไร | ราคา |
|---|---|---|
| [football-data.org](https://www.football-data.org/client/register) | แมตช์ ผลงาน ทีมในลีก (จำเป็น) | มีแพ็กเกจฟรี ตรวจว่าแพ็กเกจรวมลีกที่ต้องการ (PL, PD, SA, BL1, FL1, CL) |
| [The Odds API](https://the-odds-api.com/) | ราคา 1X2 จากหลายเจ้ามือ (ไม่บังคับ) | มีแพ็กเกจฟรีจำกัดโควตา |

ถ้าไม่ใส่ key ของ The Odds API แอปจะทำงานต่อได้ แต่ไม่มีส่วนราคาตลาดและไม่มี EV

## Deploy ขึ้นอินเทอร์เน็ต

หน้าเว็บนี้ต้องมีเซิร์ฟเวอร์ของตัวเองเพราะต้องเรียก API ภายนอก ใช้ Docker ได้ทุกที่ เช่น Render, Railway, Fly.io หรือ VPS

```bash
docker build -t football-analyzer .
docker run -p 8000:8000 \
  -e FOOTBALL_DATA_TOKEN=xxx -e ODDS_API_KEY=yyy \
  -v footdata:/data football-analyzer
```

ผูก volume ที่ `/data` เสมอ เพราะประวัติราคาเก็บอยู่ที่นั่น ถ้าไม่ผูก ประวัติจะหายทุกครั้งที่ deploy ใหม่

ควรใส่ key ผ่าน environment variable ของผู้ให้บริการ อย่าใส่ในโค้ด และอย่านำไฟล์ `.env` ขึ้น git

## โครงสร้าง

```
app/
  matcher.py     จับคู่ชื่อทีมข้ามแหล่งข้อมูล
  model.py       โมเดล Poisson + Dixon-Coles (ไม่มีการเรียกเครือข่าย)
  analysis.py    ตลาดราคา การเคลื่อนไหว ความเชื่อมั่น ฟอร์ม
  providers.py   ตัวเชื่อมต่อ API พร้อมแคชและ fallback
  store.py       บันทึกประวัติราคาใน SQLite
  main.py        FastAPI endpoints
  static/        หน้าเว็บภาษาไทย
tests/           เทสตัวจับคู่ชื่อ โมเดล และ API (ใช้ข้อมูลจำลอง)
```

## ข้อจำกัดที่ควรรู้

- **รายชื่อตัวจริงและผู้เล่นบาดเจ็บยังไม่มี** ผู้ให้ข้อมูลฟรีส่วนใหญ่ไม่มีข้อมูลนี้ หน้าเว็บจึงแจ้งว่ายังไม่มีข้อมูลยืนยัน ถ้าต้องการ ต้องเชื่อมแหล่งข้อมูลที่มีสิทธิ์ใช้งานเพิ่ม
- **ไม่มี xG** ในแพ็กเกจฟรีของ football-data.org
- **ราคาเปิดจริงไม่มี** แอปใช้ราคาแรกที่บันทึกไว้เป็นจุดเริ่มต้น ระบบจะดูการเคลื่อนไหวได้ต่อเมื่อดึงราคาอย่างน้อย 2 ครั้งในช่วงเวลาต่างกัน
- **โมเดลยังไม่ผ่าน backtest** ค่าตั้งต้นทั้งหมด (`RHO`, `DECAY`, `SHRINK` ใน `model.py`) ยังไม่ได้ปรับเทียบกับผลจริง ก่อนใช้ตัวเลขตัดสินใจเรื่องเงิน ควรทดสอบย้อนหลังและดูว่าเปอร์เซ็นต์ตรงกับความถี่จริงหรือไม่
- **การเรียกข้อมูลมีแคช** เพื่อไม่ให้เกินโควตา ผลการแข่งขันอัปเดตทุก 1 ชั่วโมง ราคาทุก 15 นาที และถ้าดึงใหม่ไม่ได้ แอปจะใช้ข้อมูลเก่าและแสดงเวลาที่ดึงมา

## ข้อความถึงผู้ใช้

ผลทั้งหมดเป็นการคาดการณ์เชิงสถิติ ไม่ใช่ผลที่รับประกัน EV เป็นค่าประมาณตามสมมติฐานของโมเดล ไม่ได้ยืนยันว่าจะทำกำไรได้จริง การเดิมพันมีความเสี่ยงสูง ควรเดิมพันเฉพาะเงินที่ยอมเสียได้ และหากเริ่มควบคุมไม่ได้ ควรขอความช่วยเหลือ
